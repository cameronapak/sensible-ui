# Sensible UI components

Package version: 1.8.1. Generated by build-agent-docs.ts from the gallery's shared HTML examples; do not edit this file directly.

Read only the sections needed for the task. Examples may compose several components: import each one's CSS when using standalone modules. The complete root CSS import already includes core components and named layouts, but not atomic utilities or highlighted code. For scoped mode use the matching scoped CSS subpath; see [usage](usage.md). Preserve consumer theme overrides; see [design guidance](design.md).

## Typography

CSS import: `@faith-tools/sensible-ui/typography`.

Use semantic headings, paragraphs, lists, quotations, and code.

```html
<article>
  <h1>A clear heading</h1>
  <p>Use <strong>semantic HTML</strong> for meaning and <em>emphasis</em>.</p>
  <blockquote>Good defaults should support the content.</blockquote>
  <p>Press <kbd>Ctrl</kbd> + <kbd>K</kbd> to search.</p>
  <pre><code>const greeting = "Hello";</code></pre>
</article>
```

## Buttons

CSS import: `@faith-tools/sensible-ui/button`.

Use native buttons for actions and a.button for navigation. Variants: primary (default), secondary, outline, ghost, link, destructive. Sizes: default, sm, lg, icon. Name icon-only controls; use native disabled and ARIA pressed/busy/invalid state.

```html
<div class="cluster">
  <button type="button">Primary</button>
  <button type="button" data-variant="secondary">Secondary</button>
```


## Named layouts

CSS import: `@faith-tools/sensible-ui/utils`.

Use stack/y-stack, x-stack, cluster, split, auto-grid, and container. Tune --layout-gap and --min-item-size. The complete core includes these; standalone compositions also need their component styles.

```html
<div class="stack">
  <div class="cluster">
    <span class="badge">Cluster</span>
    <span class="badge" data-variant="secondary">Wraps inline content</span>
  </div>
  <div class="split">
    <strong>Split layout</strong>
    <button type="button" data-size="sm">Action</button>
  </div>
  <div class="auto-grid" style="--min-item-size: 10rem">
    <div class="card"><section>First</section></div>
    <div class="card"><section>Second</section></div>
    <div class="card"><section>Third</section></div>
  </div>
</div>
```

## Atomic utilities

CSS import: `@faith-tools/sensible-ui/utilities`.

Optional companion CSS, not part of core and not the full Tailwind API. No breakpoint-prefixed variants. Override --space-* after importing it. This example also uses card and named layouts.

```html
<div class="x-stack">
  <div class="card relative w-16 shrink-0 aspect-square overflow-hidden">
    <span class="absolute inset-0 flex items-center justify-center">1:1</span>
  </div>
  <div class="y-stack min-w-0 grow shrink" style="--layout-gap: var(--space-1)">
    <span class="sr-only">Status:</span>
    <strong>Utility example</strong>
    <p class="truncate">A long status message is truncated with an ellipsis when the available inline space is limited, preserving a compact row without wrapping into the content below or pushing neighboring controls out of view.</p>
  </div>
</div>
```

## Highlighted code

CSS import: `@faith-tools/sensible-ui/code/css`. Browser JavaScript import: `@faith-tools/sensible-ui/code`. Neither is included in the core CSS import. There is no `code/js` or `scoped/code` export.

```html
<sensible-code language="html" data-wrap="true">
  <textarea readonly><button>Save</button></textarea>
</sensible-code>
```

Without JavaScript, the textarea stays readable. With it, highlighting, Copy, and Wrap controls are added. Escape ampersands before entity names and the opening angle bracket of any literal closing textarea tag. Code CSS is standalone, not a scoped module.
