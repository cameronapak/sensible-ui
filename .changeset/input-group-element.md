Add `<sensible-input-group>` for text inputs and text areas with icons, text, and buttons inside one border. The group shows a single focus ring when its field has keyboard focus, and it takes the field's `aria-invalid` and `disabled` states. With a text area, rows of text or actions sit below it. Core CSS styles the element without JavaScript.

An optional, dependency-free script makes a click on an icon, text, or empty space focus the field. Load `dist/sensible-input-group.js` as a module or import `@faith-tools/sensible-ui/input-group/js`. Import the styles alone with `@faith-tools/sensible-ui/input-group` or `@faith-tools/sensible-ui/scoped/input-group`.
